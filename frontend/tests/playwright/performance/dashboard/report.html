      How time grows from 100 → 1000 → 10000

      Each panel is one scenario. X-axis is listing size (100, 1000, 10000 files). Solid lines are the median across repeats; faint dots are the individual repeats. The dashed line is what that browser would do if time scaled linearly from its 100-file run (10× rows → 10× time). A solid line that bends above the dash is the scaling problem.

      Milliseconds per thousand rows

      Duration ÷ (folders + files) × 1000. A flat line is O(n): each extra row costs the same. A line that rises as the listing grows means work per row is getting worse — that is where the implementation degrades.
